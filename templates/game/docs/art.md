# 美术规范

> **必须最先定，定完不要改。** 改了所有素材都要重画。

## 五项写死

| 项 | 值 |
|---|---|
| 逻辑分辨率 | `___ × ___`（必须与 `game.json` 的 `display` 一致） |
| sprite 网格 | `___ × ___` |
| 描边 | |
| 光源方向 | |
| 命名规则 | `spr_<类别>_<名>_<帧号>` |

分辨率怎么选：

- 像素风：`320×180`。1080p 上是 6 倍整数放大，4K 上 12 倍，不出毛刺。
- 矢量风：`720×405` + `game.json` 里 `scale: "fit"`。

## 色板

**列出全部 hex，不许越界。** 写"16 色像素风"等于没写。

建议先跑一个 16 色方案（下面是平台自己的 UI 色，可以直接用）：

| # | hex | 用途 |
|---|---|---|
| 1 | `#0b0b0f` | 背景最深 |
| 2 | `#1a1a24` | 背景次深 |
| 3 | `#2a2a36` | 分隔/描边 |
| 4 | `#43435a` | 暗部 |
| 5 | `#6a6a7a` | 中灰 |
| 6 | `#9a9aa8` | 次要文字 |
| 7 | `#d0d0d8` | 主要文字 |
| 8 | `#f2f2f5` | 高光 |
| 9 | `#f5a524` | 强调 1（暖） |
| 10 | `#ff6b35` | 强调 2 |
| 11 | `#4ade80` | 正向/生命 |
| 12 | `#2dd4bf` | 正向 2 |
| 13 | `#60a5fa` | 信息 |
| 14 | `#818cf8` | 信息 2 |
| 15 | `#f472b6` | 危险 |
| 16 | `#c084fc` | 特殊 |

色数越少，AI 出图一致率越高，程序也越好写（调色板索引比 hex 好管理）。

## 允许的格式

png、jpg、webp、gif、ogg、mp3、wav。**不允许** svg（运行时解码不一致，且 `assets.image` 返回 HTMLImageElement 时不保证尺寸）。

像素风素材导出时必须确保：

- [ ] 不缩放（原尺寸导出，缩放交给平台）
- [ ] 无抗锯齿边缘
- [ ] 使用限定色板内颜色
- [ ] 背景透明用真正的 alpha，不要填洋红

## AI 生成素材的 prompt 前缀

每次生成都带上这段，不要省：

```
16 色像素风，限定色板：#0b0b0f #1a1a24 #2a2a36 #43435a #6a6a7a #9a9aa8 #d0d0d8 #f2f2f5
#f5a524 #ff6b35 #4ade80 #2dd4bf #60a5fa #818cf8 #f472b6 #c084fc
16×16 网格对齐，1px 深色描边，左上光源，无抗锯齿，无渐变。
```

## 字体

`ctx2d.font` 用系统字体，不要加载自定义字体文件（v1 不支持）：

```ts
ctx.ctx2d.font = '8px monospace';
ctx.ctx2d.fillText('得分', x, y);
```

像素风下 `8px monospace` 在 320×180 逻辑分辨率里最稳定。中文字符在 8px 下会糊，**大字号或改用图片做 UI**。
