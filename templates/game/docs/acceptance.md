# 验收清单

> `typecheck` 通过不算跑通。改到玩家可见的东西，必须真跑起来并截图。

## 每次改动后的最小检查

```bash
cd ../../hearthbox
pnpm dev
```

- [ ] 游戏出现在货架上，名字和简介正确
- [ ] 点进去不是黑屏，没有崩溃页
- [ ] 控制台没有红色报错

## 完整验收（发布前）

### 能玩

- [ ] 键盘能完成一局（方向键 + 动作键）
- [ ] 手柄能完成一局（如果有手柄）
- [ ] 鼠标操作准确（如果游戏用鼠标，点哪就是哪）
- [ ] 死亡后能重开，不用刷新页面
- [ ] 有明确的开始和结束

### 存档

- [ ] 玩到一半刷新页面，进度还在
- [ ] 关掉标签页再打开，进度还在
- [ ] 换一个游戏再回来，本游戏存档没被串

### 画面

- [ ] 窗口拉大缩小，画面不变形、不糊
- [ ] 像素风边缘锐利（没有平滑模糊）
- [ ] 文字在 3 米外能看清（如果目标是电视）
- [ ] 没有元素跑到画面外

### 性能

- [ ] 连续玩 5 分钟不掉帧
- [ ] DevTools Performance 里单帧 < 16ms
- [ ] 没有内存持续增长（看 Memory 面板）

### 证据

截图存到 `evidence/`，命名 `功能-状态.png`：

```
evidence/
├── shelf.png          货架里能看到它
├── gameplay.png       正常游玩
├── gameover.png       结束画面
└── save-restored.png  刷新后进度还在
```

**没有截图的"完成"都是假的。**
